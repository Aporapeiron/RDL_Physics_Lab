# RDL_Physics_Lab

RDL_Physics_Lab は、物理現象・物理理論・宇宙論的概念を、**関係力学言語（RDL）からどのように解釈できるかを試すための実験場**である。

ここで扱うものは、原則としてすべて **記述モデル** である。

本リポジトリの主目的は、

> その解釈が最終的に正しいかどうかを決めること

ではない。

むしろ、

> **RDLを使うと、その現象・理論・観測をどのような関係構造として記述できるか**

を試すことにある。

---

## 基本姿勢

物理学には、古典力学、相対論、量子力学、熱力学、宇宙論など、多数の記述モデルが存在する。

RDL_Physics_Lab では、それらを世界そのものと同一視しない。

同様に、RDLによる解釈も世界そのものとはみなさない。

```text
現象
↓
観測
↓
既存物理による記述
↓
RDLによる再解釈
```

これらは、それぞれ異なる境界・尺度・解像度から成立する記述である。

したがって、

```text
RDL的にこう読める
```

ことは、

```text
世界は本当にこうなっている
```

ことを意味しない。

---

## 正誤よりも解釈可能性を見る

本リポジトリでは、既存物理理論の正誤を裁定することを主目的としない。

ある理論が現在の観測に強く支持されている場合も、その理論をRDLへ翻訳してみる。

未確定な仮説についても、RDLからどのように記述できるかを試す。

さらに、互いに競合する複数のモデルについても、それぞれを候補として扱うことができる。

重要なのは、

```text
どの解釈が許されるか
どの関係が見えるか
どこで記述が破断するか
どの条件で別のモデルが必要になるか
```

を観察することである。

---

## なぜこれを行うのか

理由は単純である。

> **RDLが使える道具になる可能性があるから。**

RDLによる物理解釈が、

- 複数理論を同じ枠組みで比較する
- モデルの適用境界を見つける
- 未説明差分を早く発見する
- 一つの仮説への過剰な固定を避ける
- 観測・モデル・存在論を分離する
- 異なる尺度の記述を接続する
- 新しい仮説候補を展開する

といった作業に有用なら、RDLは単なる説明語彙ではなく、実際の探索道具になりうる。

その可能性を検査することが、このLabの目的である。

---

## 閉じない

観測と現在モデルの間に差異が生じた場合、その原因を一つに固定しない。

例えば、

```text
観測差分
├─ 未知の物質・構造
├─ 現在理論の不足
├─ モデル化の不足
├─ 観測境界の問題
├─ 解像度の問題
├─ 初期条件・履歴の不足
├─ 複数要因
└─ 現在まだ想定していない候補
```

を開いておく。

候補は検査によって絞ることができる。

しかし、説明できていない段階で一つの候補を世界そのものとして固定しない。

---

## RDLによる物理解釈

必要に応じて、物理現象を次のようなRDL語彙へ展開する。

```text
B
    観測・記述・操作の有限境界

ρ
    どこまで細かく関係差を記述するかという解像度

Δ
    二つの断面の操作的な隔たり

ξ
    現在の有限記述では回収されない関係

SILN
    関係ネットワーク上で保持される有限構造

RIB / RIB_B
    相互作用と、その有限な作用断面

M_B
    現在採用している有限関係拘束構造
```

ただし、これらも最終的な存在論ではない。

必要なときに現象を展開するための記述道具である。

---

## 原則

> **通常の物理記述で問題がなければ、そのまま使う。**

> **問題が生じたときだけ、より細かな関係構造へ展開する。**

> **すべてを最初からRDL語彙へ還元する必要はない。**

RDL_Physics_Lab は、物理を置き換えるための場所ではない。

物理を別の角度から読み、既存モデルの境界を見つけ、必要なら別の可能性を開くための場所である。
